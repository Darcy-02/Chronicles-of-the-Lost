Chronicles-of-the-Lost

 Overview

**Chronicles-of-the-Lost** is an action-packed fighting game developed using Unity. The game challenges players to progress through five different levels, facing increasingly challenging opponents along the way.

Players must defeat each opponent to advance to the next level, testing their combat skills, timing, strategy, and ability to adapt to different fighting styles.

The game is designed to provide an engaging experience across PC, Web, and Mobile platforms.

 Game Features

- **5 Progressive Levels:** Fight through five levels, each featuring a different opponent.
- **Multiple Opponents:** Face different enemies with varying levels of difficulty.
- **Combat System:** Engage opponents using the available fighting mechanics.
- **Main Menu:** Navigate the game's main interface.
- **Settings Menu:** Access and adjust available game settings.
- **Cross-Platform Gameplay:** Play on PC, Web, and Mobile.
- **Level Progression:** Defeat opponents to unlock or progress to subsequent levels.

 Gameplay

The objective is to defeat all five opponents and successfully complete every level.

### Level Structure

| Level | Challenge |
|---|---|
| Level 1 | First opponent |
| Level 2 | Second opponent |
| Level 3 | Third opponent |
| Level 4 | Fourth opponent |
| Level 5 | Final opponent / Boss |

Each level introduces a new opponent, providing a progressive fighting challenge.

 

### Running the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Darcy-02/Chronicles-of-the-Lost.git
   ```

2. Open Unity Hub.
3. Select **Add Project**.
4. Choose the cloned project folder.
5. Open the project using the compatible Unity version.
6. Open the main game scene.
7. Press the Play button to start playing.
